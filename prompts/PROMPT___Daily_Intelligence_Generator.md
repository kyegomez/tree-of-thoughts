# Daily Intelligence Generator Prompt

## Purpose
Analyze daily capture data and generate actionable insights, patterns, and recommendations based on metrics, projects, and reflections.

## Input
Daily capture JSON with:
- Date, metrics (8 items), projects (4 items), free-write journal, optional IFS insights

## Task
Generate a comprehensive daily intelligence report covering:

### 1. **Daily Summary** (2-3 sentences)
- Synthesize the overall day's quality and achievements
- Highlight the most significant win and learning

### 2. **Metrics Analysis** (structured breakdown)
For each metric category (Health, Productivity, Learning, Relationships):
- Current score trend (up ↗️, stable →, down ↘️)
- What drove the score
- One micro-improvement opportunity

### 3. **Project Velocity Assessment**
- Which project has strongest momentum
- Which needs attention or unblocking
- Estimated completion timeline for each

### 4. **Pattern Recognition**
- Identify recurring themes across metrics and journal
- Connection between energy levels and productivity
- Behavioral patterns emerging

### 5. **Key Insights** (3-5 bullets)
- Most important discovery from today
- Potential blind spots
- Leverage points for tomorrow

### 6. **Personalized Recommendations** (3 actions)
- Tomorrow's focus area
- One recovery/restoration activity
- One capability-building activity

### 7. **IFS Integration** (if applicable)
- Which internal parts were active today
- Their protective strategies
- Integration suggestions

## Output Format
```
# Daily Intelligence Report - [DATE]

## ✨ Daily Summary
[2-3 sentences]

## 📊 Metrics Deep Dive
[Structured analysis by category]

## 🎯 Project Velocity
[Status and momentum]

## 🔍 Pattern Recognition
[Themes and connections]

## 💡 Key Insights
- [Insight 1]
- [Insight 2]
- [Insight 3]

## 🚀 Tomorrow's Recommendations
1. [Action 1]
2. [Action 2]
3. [Action 3]

## 🧠 Internal Dynamics
[IFS insights if captured]
```

## Tone
- Insightful and analytical
- Encouraging but honest
- Personal and contextual
- Action-oriented
