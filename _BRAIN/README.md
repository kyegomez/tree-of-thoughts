# 🧠 Daily Intelligence System

## Structure

```
_BRAIN/
├─ DAILY_CAPTURES/        → Captures quotidiennes brutes
├─ DAILY_REPORTS/         → Rapports générés par Claude
├─ WEEKLY_REVIEWS/        → Synthèses hebdomadaires
├─ MONTHLY_DEEPDIVES/     → Analyses mensuelles approfondies
├─ PATTERNS/              → Détections de patterns détectées
├─ RECOMMENDATIONS/       → Recommandations et actions
└─ _TEMPLATES/            → Templates réutilisables
```

## Workflow

1. **Chaque jour** → Capture quotidienne dans `DAILY_CAPTURES/`
2. **Avec Claude** → Générer rapport dans `DAILY_REPORTS/`
3. **Chaque semaine** → Synthèse dans `WEEKLY_REVIEWS/`
4. **Chaque mois** → Deep dive dans `MONTHLY_DEEPDIVES/`
5. **Continu** → Patterns détectés dans `PATTERNS/`
6. **Actions** → Recommandations dans `RECOMMENDATIONS/`

## Files associés

- `DAILY_INTELLIGENCE_SYSTEM.md` - Vue d'ensemble complète
- `README_DailyIntelligence.md` - Guide détaillé
- Prompts Claude dans `_TEMPLATES/`
